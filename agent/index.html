Use Geometrica with an AI agent

Describe the artwork you want, and an AI agent composes the layers for you.

How it works

Geometrica runs entirely in your browser and offers its tools to AI agents through WebMCP; there is no Geometrica server. Claude Code reaches into the browser through Chrome DevTools MCP, a small helper that runs on your machine via Node.js and opens its own Chrome window.

You need

  • Claude Code
  • Chrome 150 or later
  • Node.js

1. Connect Claude Code

Run this once in a terminal:

claude mcp add --scope user chrome-devtools -- npx -y chrome-devtools-mcp@latest --categoryExperimentalWebmcp=true --chromeArg=--enable-features=WebMCP

In a running session, run /mcp to connect, or restart Claude Code.

Working on Geometrica itself? Claude Code started in the repository offers the helper from .mcp.json, so you can skip this step.

2. Ask for an artwork

Tell Claude Code where Geometrica is and what you want:

Open %VITE_APP_URL% and draw a tunnel of twenty rounded squares spiralling inwards in magma colors.

The browser's back button undoes the agent's changes, except the first one after opening Geometrica without a link.
